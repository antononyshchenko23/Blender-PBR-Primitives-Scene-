# Blender PBR Primitives Scene

This repository contains a practice 3D scene created in Blender, showcasing basic geometric primitives with physically based (PBR) materials.

## Scene Overview

The scene features five main objects set upon a reflective plane:
- **Mirror Cube:** Fully reflective surface showing environment reflections.


- **Diamond Sphere:** Glass material with light refraction.- **Textured Stone Cone:** Surface with detailed displacement.
- **Glowing Red Monkey:** Suzanne model with emissive lighting.



## Rendering

- **Engine:** Rendered in Cycles.
- **Environment:** Illuminated by a 360-degree forest HDRI map.
